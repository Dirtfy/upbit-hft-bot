# 하락장 방어 전략 — 요약 보고서

*대상: 업비트 KRW-BTC · 연구/모의(PAPER) 단계 · 실거래는 기본 OFF*

---

## 1. 전략이 하는 일 (핵심)

- **상승장 = BTC 보유**, **하락장 = 원화(KRW) 현금 보유.**
- 즉 "수익을 극대화"하는 전략이 아니라 **손실을 피하는(방어) 전략**입니다.
  업비트는 현물만 거래되어 공매도가 불가능하므로, 하락장에서 할 수 있는
  최선은 **현금으로 빠져 큰 하락을 피하는 것**입니다.
- 상승 추세로 판단되면 BTC를 사서 들고, 하락 추세로 판단되면 전량 팔아
  현금으로 대기합니다. (한 번에 한 포지션, 매수는 리스크 한도 내에서만.)

## 2. 하락장(약세장)을 어떻게 판단하나

아래 **둘 중 하나라도** 해당하면 "하락장"으로 봅니다.

1. **추세:** 가격이 **200일 이동평균선 아래**로 내려감. (장기 추세 이탈)
2. **낙폭:** 최근 1년 고점 대비 **-20% 이상** 하락. (통상적인 약세장 정의,
   급락에 더 빠르게 반응하는 안전장치)

**되돌림(anti-churn) 버퍼:** 한 번 하락장으로 판단하면, 가격이 이동평균선을
다시 **넘고** 낙폭도 회복되어야 상승장으로 되돌립니다. 경계선에서 매수·매도를
반복(휘프소)하는 것을 줄이기 위한 완충 장치입니다.

## 3. 백테스트 핵심 결과 (KRW-BTC 일봉, 약 9년)

`backtest/bear_backtest.py` 실행 결과. 핵심은 **최대낙폭(MDD) 감소**입니다.

| 구분 | 단순 보유(buy&hold) | 하락장 방어 전략 |
|---|--:|--:|
| **최대낙폭(MDD)** | **86.8%** | **27.7%** |
| 2018 약세장 구간 수익률 | **-77.7%** | **0.0%** (현금 대기) |
| 2021–22 약세장 구간 수익률 | **-73.5%** | **-7.3%** |

- **최대낙폭이 86.8% → 27.7%로 크게 줄었습니다.** 즉 계좌가 겪는 최악의
  손실 폭을 3분의 1 수준으로 낮춥니다.
- 2018년 약세장(단순 보유 -78%)은 **전 기간 현금 대기로 0%**, 2021–22년
  약세장(-73%)은 **-7%대**로 방어했습니다.
- 대가로 **상승장 수익의 일부는 포기**합니다(시장에 있는 기간이 짧음). 목적이
  수익 극대화가 아니라 **손실 회피**이기 때문입니다.

**한계(솔직하게):** 단일 종목·단일 기간, 매매 횟수가 많지 않아 정확한 수익률은
불확실합니다. **낙폭 감소**가 신뢰할 수 있는 결론이며, 정확한 수익률 수치는
그대로 받아들이지 마세요.

**현재 신호(2026-09-23 기준):** 장세 = **하락장**(BTC가 1년 고점 대비 약 -30%),
따라서 전략은 지금 **현금 대기(FLAT)** 상태입니다 — 설계대로 동작 중입니다.

## 4. 안전장치 (실거래는 기본 꺼짐)

- 실거래 주문은 **기본적으로 나가지 않습니다.** 기본은 DRY-RUN(모의)로,
  "낼 주문"을 로그로만 남기고 API 키도 쓰지 않습니다.
- 실거래는 **4가지가 모두** 충족될 때만 가능합니다: `LIVE_TRADING_ENABLED=True`
  (기본 False) + `--live` 옵션 + `"TRADE LIVE"` 문구 입력 + API 키 존재.
- 모든 매수는 공용 리스크 매니저가 통제합니다: **총 노출 100만 KRW 상한**,
  건별 사이즈 제한, 일일 손실 kill-switch.
- 자세한 설계·근거·인용 문헌: `research/BEAR_MARKET_STRATEGY.md`.
  실행 방법: `OPERATIONS.md`. 구조도: `docs/architecture.png`.
