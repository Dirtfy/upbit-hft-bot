# paper_trading — 공식 모의투자 기록 (2026-09-25 시작)

오너 미션에 따라 약 1개월간 **모의투자(paper trading)** 기간을 공식 운영하며,
그 기록을 이 디렉터리에 **커밋/푸시**로 축적한다.

## 안전 (변경 없음)
- **실거래 주문 없음, API 키 없음, 계좌 접근 없음.** 공개 시세(read-only)만 사용.
- 가상 자본 **1,000,000 KRW**, 노출 상한 1,000,000 KRW, 모든 리스크 한도 유지.
- 전략 신호는 백테스트와 **동일한 코어**(`src/regime.py` + `src/bear_strategy.py`)를
  그대로 사용 — 기록된 것이 곧 검증된 로직이다.

## 무엇을 기록하나
매 사이클(마감된 일봉 1개 = 1 사이클)마다:

| 파일 | 형식 | 내용 |
|---|---|---|
| `JOURNAL.md` | 사람이 읽는 저널 | 사이클별 장세·신호·행동·**진입/청산 근거**·손익(사이클/누적) |
| `paper_log.jsonl` | 기계 판독 원장 | 위와 동일 정보를 사이클당 JSON 1줄로(누적) |
| `market_data_daily.csv` | 축적 시세 | 그 사이클에 쓴 일봉 OHLC(백테스트용 커밋 데이터셋) |

손익 정의: 판단=마감 일봉, 체결가=해당 봉 종가, 수수료 0.05%/편도, 한 번에 한
포지션. `equity = 현금 + BTC평가액`, 사이클 손익 = 직전 대비 평가액 변화, 누적
손익/수익률 = 시작 1,000,000 KRW 대비.

## 실행
```bash
python3 paper_trading/paper_trader.py            # 기본 모드 long_flat
python3 paper_trading/paper_trader.py --mode breakout_regime
```
**멱등(idempotent):** 마지막으로 기록한 봉 이후의 새 봉만 추가하므로 아무 때나
다시 돌려도 안전하다. 첫 실행은 그 시점의 최신 마감 봉에서 시작(과거 백필 없음 —
앞으로의 전진 기록).

일일 사이클 케이던스(하루 1회)면 일봉 1개/일이 정확히 축적된다.

## 4시간봉(4h) 축적 — 오너 옵션 A (2026-09-26)

일봉 축적은 그대로 두고 4시간봉 축적을 병행한다.

```bash
python3 paper_trading/collect_4h.py            # 첫 실행: 최근 ~30일(180봉) 부트스트랩
paper_trading/run_4h_collector.sh              # 스케줄용 래퍼(로그 남김)
```
- 저장: 커밋되는 전진 축적 트레일 **`market_data_4h.csv`**(time,OHLC,volume).
  전체 9년 4h 원시데이터는 기존 규약대로 gitignore된 `data/krw_btc_4h_full.csv`.
- **무결성**: 매 실행 후 중복·역순·갭(4h 간격)을 검사해 출력(정상 시 모두 0).
- **갭 없는 설계(self-healing)**: 매 실행이 "마지막 기록 이후 마감된 모든 4h봉"을
  백필하므로 케이던스와 무관하게 완전하다. 하루 1회 리더 턴만 돌아도 그날의 4h봉
  6개가 백필로 모두 축적된다. 4시간 주기 크론은 '완전성'이 아니라 '신선도'만 개선.
- **스케줄**: 시스템 크론이 없고, 세션 기반 크론은 리더 턴 사이에 잠들어 한 달간
  4h 주기를 보장하지 못한다. 따라서 완전성은 위의 백필로 보장하고(리더가 매
  사이클 실행), 진짜 4시간 주기가 필요하면 상시 호스트에 크론 1줄을 건다 —
  `run_4h_collector.sh` 주석의 crontab 예시(`7 */4 * * *`) 참고. 상세는 `report.txt`.

### 4h 모의투자 트랙(선택) — 일봉 원장과 분리
현재 방어 전략의 장세필터는 **일봉 기준(SMA200 등)**이라 4h봉에 그대로 적용하면
의미가 달라진다. 그래서 이번 단계는 **4h 데이터 축적까지만** 수행한다. 4h 기반
모의투자 트랙이 필요하면 4h에 검증된 전략(리서치의 Donchian 30/20)으로 **별도
디렉터리·별도 원장**에 구성하며, 일봉 원장(`paper_log.jsonl`)과 절대 섞지 않는다
(모드 일관성 가드 유지).
